# S01

This project is a simple html/JavaScript page that displays a button which now reads "Click If You Dare!" (Instead of just "Click Me!") along with a counter variable. When the button is clicked, the page will now increment the counter variable by 1 each time, and the text within the button will update to read "Oh wow you really did it." This was done by updating the .textContent of both the button and counterElement handlers, while casting the updated counter to a string for the counterElement.
